# Go-Reloaded

## Description
Go-Reloaded is a text formatting tool that applies a series of transformations to an input file based on embedded markers. It handles hexadecimal and binary conversions, casing adjustments, punctuation formatting, and grammar corrections.

## Usage
To run the tool, use the following command:

```bash
go run . <input_file> <output_file>
```

## Features
* Hex/Bin conversion
* Casing transformations (up, low, cap)
* Punctuation formatting
* Grammar correction (a -> an)
